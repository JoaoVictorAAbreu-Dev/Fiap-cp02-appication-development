# Calculadora de IMC — Equilíbrio

Checkpoint de **Application Development**, turma **2CCPH**.

Aplicação React para calcular o IMC, consultar a classificação e acompanhar medições salvas no navegador.

## Funcionalidades
- Cálculo de IMC com altura em metros ou centímetros.
- Validação dos campos e tabela de classificação.
- Histórico local, remoção de medições e exportação CSV.
- Tema claro e escuro; layout responsivo.

## Executar
Requisitos: Node.js 22.12 ou superior e npm.

```bash
npm ci
npm run dev
```

```bash
npm test
npm run lint
npm run build
```
